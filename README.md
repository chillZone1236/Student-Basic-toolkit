# 🎓 StudentToolkit

A free collection of simple and useful tools made for students.

## 🛠️ Available Tools

* 🧮 Percentage Calculator
* 🎯 Required Marks Calculator
* 📊 Average Marks Calculator
* 🔢 CGPA to Percentage Calculator
* 🎂 Age Calculator
* ⏱️ Custom Study Timer

## ✨ Features

* Completely free to use
* Simple and clean interface
* Works on mobile and desktop
* No account or sign-up required
* Fast and lightweight

## 💻 Built With

* HTML
* CSS
* JavaScript

## 🚀 Project Status

StudentToolkit is currently under development. More useful student tools and features will be added over time.

## 📌 Goal

The goal of StudentToolkit is to create a simple, free, and useful website where students can access everyday tools in one place.
